落下原理（簡報 p2/p3）：黑塊的列位置由 `i`（6→0）與 `j=count` 共同決定；每按一次 So 鍵 `count++`，重畫時所有黑塊往下移一列，最上面的音消失，形成「樂譜落下」效果。

介面控制項：7 個音鍵按鈕（Do~Si，y=390）、左上 ComboBox、四個功能按鈕、狀態標籤，宣告於 Form1.Designer.cs。

- ComboBox 選「小蜜蜂(整首)」即切換 `arrCur = arrbeeFull`、`maxCur = 49`。
- 因為 paintTable 的填色迴圈只畫「目前視窗內 7 列」，整首曲子會隨著 count 增加（落下）逐步顯示後面的音，正好符合別踩白塊兒的玩法。

## 三、作業 3：結合 Timer 自動播放、色塊跟著移動（10%）

- 新增 `System.Windows.Forms.Timer tmrPlay`（Interval=650ms，略大於節拍間隔）。
- 按「自動播放」→ `tmrPlay.Start()`；每個 Tick：
  1. 取 `arrCur[playIndex]` 得到音級 1~7，呼叫 `PlayNote(note-1)` 發聲；
  2. `playIndex++`、`count = playIndex`；
  3. 呼叫 `paintTable(arrCur, maxCur)` 重畫 → 黑塊整排往下落一格。
- 如此聲音與色塊同步移動，達成自動播放。

## 四、作業 4：播完可繼續使用／重新播放（10%）

- Tick 中若 `playIndex >= maxCur`：停止 Timer、狀態列顯示「播放完畢」，程式回到可操作狀態（仍可手動彈琴鍵、鍵盤 1-7、換歌）。
- 「停止」按鈕：停 Timer、count 歸零重畫，保留手動彈奏能力。
- 「重新播放」按鈕：count 與 playIndex 歸零後重新啟動 Timer，可無限次重播。
- 播放中按「自動播放」可暫停，再按繼續（從暫停處接續）。

## 七、作業 7：程式碼優化、播放接近原曲旋律（20%）

1. **鋼琴聲（Windows Media Player）**：Do~Si 對應 C、D、E、F、G、A、B 七個音的 wav 檔，用官方建議的 Windows Media Player 播放。
   - 讀取方式（依官方文件）：音檔放在 exe 目錄（`bin\Debug\...` 或 `bin\Release\...`）下的 `Music_Notes` 資料夾，程式用
     `string directory = AppDomain.CurrentDomain.BaseDirectory;`
     `string path = Path.GetFullPath(directory + @"\Music_Notes\C.wav");` 取得完整路徑。
   - 播放方式（等同官方 `WMPLib` 寫法）：
     `player = new WindowsMediaPlayer(); player.URL = path; player.controls.play();`
   - **實作細節**：本機 Windows Media Player 的型別程式庫（TypeLib）未註冊，無法產生強型別的 `WMPLib` 互操作組件，因此改用「晚期繫結」建立同一個 COM 元件 `WMPlayer.OCX`（`Type.GetTypeFromProgID("WMPlayer.OCX")` + `Activator.CreateInstance`），呼叫完全相同的 `URL` 與 `controls.play()`。行為與官方範例一致，且不需額外註冊或安裝元件。
   - 找不到音檔時自動退回簡報原本的 `Console.Beep`，程式不會報錯。
2. **旋律優化**：發聲與畫圖分離（PlayNote / PlayPiano / StepDown / paintTable 各司一職）；七个音鍵共用同一個 `PlayNote(i)`，消除重複程式碼。
3. **節拍**：自動播放以 Timer 固定間隔推進，節奏穩定接近原曲速度。

## 八、附加功能：新增 mp3 等音檔歌曲

- 「＋新增 mp3 音檔歌曲」按鈕開啟 OpenFileDialog（Filter：mp3/wav/wma/m4a/flac/ogg，可多選）。
- 選取的檔案加入 `mediaFiles` 清單，並在 ComboBox 新增「檔名(mp3)」項目、自動切換到該項。
- 播放方式：切換到音檔項目後按「自動播放」，同樣使用 Windows Media Player（`WMPlayer.OCX`）播放 mp3 等音檔；同一按鈕可暫停/繼續，「停止」按鈕停止音檔。
- 好處：不需額外安裝元件，Windows 內建解碼器即可播放 mp3。

## 操作快速指南

1. 滑鼠點 Do~Si 按鈕，或鍵盤按 1~7 彈奏（需 KeyPreview，已於 Shown 設定）。
2. 按 So(5) 鍵：樂譜黑塊落下一步（上課原始行為）。
3. ComboBox 選曲 → 「自動播放」看色塊邊落邊演奏 → 播完可「重新播放」或「停止」後手動彈。
4. 「更改鋼琴塊顏色」換黑塊顏色。
5. 「＋新增 mp3 音檔歌曲」加入自己的歌，選到該項按「自動播放」即播放音檔。
6. 鋼琴聲：專案已含 `Music_Notes` 音檔（C~B.wav），建置時自動複製到 exe 旁，執行即有鋼琴音色。
